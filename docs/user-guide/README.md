# User Guide (0.1.0 developer preview)

## What works today

- **Home**: live status of the JACK service and its components, plus a command box. Typed
  commands are saved as durable tasks. JACK does not act on them yet; planning and execution
  arrive in Milestones 5–7.
- **Active Tasks**: every task with its full timeline. Pause, resume and cancel are recorded permanently.
- **Security**: the audit log of everything that happened, including rejected access attempts, with a
  one-click integrity check of the tamper-evident chain.
- **Settings**: dark, light or system theme, accent colour, compact sidebar.
- **System tray**: closing the window keeps JACK running. Use the tray menu to reopen, restart the service, or quit.

## Keyboard shortcuts

| Keys | Action |
|---|---|
| Ctrl+1 | Home |
| Ctrl+2 | Active Tasks |
| Ctrl+3 | Security |
| Ctrl+, | Settings |
| Ctrl+B | Toggle compact sidebar |

## Not available yet

Voice and the wake word "Jack" (Milestone 3), Claude integration (M4), GitHub (M9), servers (M10),
deployments (M13), creative studio (M14) and the rest are marked in the app with the milestone that delivers them.
